# Bird Audio Classification

Учебный проект по классификации видов птиц по аудиозаписям. Эксперименты выполнены в июне 2026 года. Используются свёрточная нейронная сеть (CNN), Mel-спектрограммы, SpecAugment и отбор аудиофрагментов по RMS.

## Данные

Источник: [Xeno-canto](https://xeno-canto.org/). Исходная выборка включала 2 974 записи 15 видов птиц (качество A/B, исключены записи с меткой страны Russia). Для основной серии экспериментов отбиралось до 175 записей на класс.

Разделение train/validation/test (70/15/15) стратифицировано по виду и выполняется на уровне исходных записей до сегментации. Это исключает попадание сегментов одной записи в разные выборки, но не гарантирует независимость по автору, месту или особи. В `data/recordings.csv` сохранён реконструированный список из 2 624 записей с идентификаторами, метками, авторством и лицензиями; точные разбиения исторических запусков отсутствуют.

## Метод

- Аудио: mono, 32 кГц, сегменты по 5 секунд, до пяти сегментов на запись.
- Mel-спектрограммы: 128 Mel-бинов, FFT 2048, hop 512, z-score нормализация.
- CNN: четыре свёрточных слоя (32, 64, 128, 256 каналов), BatchNorm, ReLU, MaxPool, AdaptiveAvgPool, Dropout 0.3.
- SpecAugment: маскирование времени и частот только при обучении.
- Adam (lr 0.001, weight decay 0.0001), CrossEntropyLoss, выбор чекпоинта по validation Macro F1, early stopping.

При равномерной сегментации окна распределяются по всей записи. При RMS-сегментации выбираются до пяти окон с наибольшей среднеквадратичной амплитудой, шаг — 1 секунда. Высокий RMS не гарантирует присутствие целевой птицы: активным может быть фоновый шум.

## Результаты

| Эксперимент | Классы | Тестовые сегменты | Accuracy | Macro F1 |
|---|---:|---:|---:|---:|
| CNN + SpecAugment, равномерная нарезка | 15 | 1446 | 0.4557 | 0.4561 |
| CNN + SpecAugment, равномерная нарезка | 10 | 939 | 0.5602 | 0.5579 |
| CNN + SpecAugment, RMS-сегментация | 10 | 1154* | 0.7400 | 0.7487 |

*Метрики последней строки записаны в тексте исходного ноутбука; число сегментов взято из соседнего лога. Сохранена матрица ошибок, но веса и предсказания этого запуска отсутствуют. Метрики не пересчитаны.*

![Матрица ошибок CNN с RMS-сегментацией](results/cnn10_rms_confusion_matrix.png)

Результаты относятся к отдельным историческим экспериментам, а не к контролируемой абляции: число классов, состав выборок и тестовые сегменты менялись. Десять классов выбраны после анализа исходных результатов, поэтому их показатели нельзя трактовать как независимое подтверждение улучшения на 15 классах. Другие ранние запуски, черновики AST и отдельный BirdNET zero-shot эксперимент не включены в сокращённую версию репозитория. Полные архивы следует хранить отдельно.

## Запуск нового эксперимента

Python 3.10–3.12, рекомендуется GPU. Из корня репозитория:

```bash
python -m pip install -r requirements.txt
python scripts/prepare_data.py --manifest data/recordings.csv --classes 15 --segmentation uniform --out local/uniform15 --download
python scripts/train_cnn.py --segments-dir local/uniform15 --out runs/cnn15
```

Для эксперимента на десяти классах с RMS-сегментацией:

```bash
python scripts/prepare_data.py --manifest data/recordings.csv --classes 10 --segmentation rms --out local/rms10 --download
python scripts/train_cnn.py --segments-dir local/rms10 --out runs/cnn10_rms
```

Без `--download` используется локальная папка `local/audio`. Перед скачиванием проверяйте условия лицензий конкретных записей. Аудио и веса в репозитории не распространяются. Новые запуски сохраняются в `runs/` и не изменяют исторические результаты. Для чистого сравнения сегментаций нужны одинаковые ID записей в разбиениях, один набор классов и общая тестовая выборка.

Скрипты выделены из исходного ноутбука и адаптированы для новых запусков. Точное окружение и split старых экспериментов не восстановлены; после рефакторинга полный цикл скачивания и обучения не запускался. Версии библиотек в `requirements.txt` — минимальные требования, а не зафиксированное историческое окружение.
